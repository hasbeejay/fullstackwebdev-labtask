### ✨ Features

- 👋 **Welcome widget** — a time-of-day greeting for the instructor
- 🕒 **Live clock** — analog clock with digital time, date and time zone
- 🪪 **Student info card** — name, roll number, class, instructor, university
- 🗂️ **Lab cards** — one per completed lab, with a numbered icon, description, GitHub link, and a link to the hosted page
- 📄 **Lab pages** — a details page per lab with previous/next navigation
- 🌗 **Light & dark mode** — follows the system theme, with a manual toggle
- 📱 **Responsive** — adapts down to phone width
- ♿ **Accessible** — semantic HTML, visible focus states, skip link, reduced-motion support
- ⚡ **Zero dependencies** — plain HTML, CSS and JavaScript, no build step
