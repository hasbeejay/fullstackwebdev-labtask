GROUND RULES

Constraints followed in every task

No DOM, HTML, React, Express, databases or external packages: plain Node.js ES modules
No closure-based state: no function returns an inner function to remember anything
const and let only, strict equality (===) throughout
Source data is never mutated; every function returns a meaningful result
Invalid and unexpected data handled, with normal, boundary and invalid test cases
Nothing hard-coded: every figure in the output is calculated by the code
RUN IT YOURSELF
