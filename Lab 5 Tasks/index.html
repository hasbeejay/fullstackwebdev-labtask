01 / Overview

One case study.
Eight core skills.

CampusFlow is a proposed academic operations system for Air University. The lab asks you to implement and test its core business logic before connecting it to a web interface. You will work with imperfect student data, academic results, user hierarchies, JSON transcripts, and services that complete asynchronously.

Lab rule: Focus on Node.js and JavaScript logic. The handout prohibits DOM manipulation, HTML, React, Express, databases, and external packages for the actual lab solutions.

03 / Learning path

Build concepts
in the right order.

The later tasks become easier when the earlier JavaScript fundamentals are solid. Use this sequence as a study guide, then follow the exact requirements in the lab sheet.

01
Data & transformations

Tasks 1–2: validation, calculations, conditions and array methods.

02
Objects & architecture

Tasks 3–5: immutable updates, classes, dynamic this, modules and JSON errors.

03
Asynchronous programming

Tasks 6–7: error-first callbacks, Promise chains and Promise combinators.

04
Concurrent services

Task 8: Fetch-like requests, concurrent execution, dashboard aggregation and timeout cleanup.

04 / Get started

Run it with Node.js.

Create separate files for each task and execute them from the terminal. Task 5 should have its own module folder with a package.json configured for ES modules.
