03 / NOTES

Requirements & explanation

Requirements covered

Returns a new student, the original object is never modified
address.city changes while address.sector remains
contact.email remains and contact.phone is added
0, false and "" are not replaced by defaults
Object, nested, renamed and default destructuring; array destructuring; rest parameters; object rest
Spread, optional chaining, nullish coalescing and property shorthand
Reference comparison of original vs updated, address and contact

Reference challenge: all three are different

Objects are compared by reference (their location in memory), not by content. updateStudent() starts from structuredClone(student), so the result, its address and its contact are each separate objects: all three comparisons print false.

The reverse is shown too. A shallow copy made with { ...student } gives a new outer object but shares the same address. Changing shallow.address.city then changes the original, which is exactly the bug a safe update service must avoid.

?? versus ||

|| replaces every falsy value, so 0 || 85 is 85 and a student's zero marks would be overwritten. ?? only falls back for null and undefined. In the merge, only undefined means "this field was not provided"; everything else, including 0, false, '' and null, is a real value.
